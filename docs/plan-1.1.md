# 雪耳 1.1 计划

> 2026-11-19 和主人讨论定稿。主人确认后一次做完；推送、发版到时候单独问。

## 一、面板

猫耳面板：左边「设置」，中间麦克风，右边「翻译」。

| 位置 | 按钮 | 点了之后 |
|---|---|---|
| 左 | 设置 | 打开雪耳控制面板（和托盘右键「设置」是同一个） |
| 中 | 麦克风 | 和现在一样：开始 / 停止听写 |
| 右 | 翻译 | 弹出一个翻译小窗 |

### 翻译小窗

- 上面一格输入（可以打字，也可以粘贴），下面一格出英文。
- 输入停下约半秒后自动翻译，回车也会立刻翻译。
- 有「复制」按钮；按 Esc 或点外面就关掉。
- 中文翻成英文；输入的是英文，就翻成中文。
- 外观和猫耳面板是同一套：黑白灰、圆角，不加大标题。

## 二、说「翻译」

- 一轮听写的最后，单独说「翻译」「英文」「翻译成英文」或「说英文」。
- 这一轮雪耳打出来的字会全部擦掉，换成英文。
- 翻完不自动发送，主人看过再说「发送」或者按回车。
- 话说到一半提到「翻译」，还是当普通文字打出来。
- 已知边界：主人在这一轮里手动改过的字，翻译时按雪耳记下的原话来，手改的部分不算进去。手打的内容想翻译，就用翻译小窗。
- 翻译失败时，屏幕上的中文保持不动，面板上提示原因。

## 三、翻译服务

- 主力：微软翻译（Azure Translator F0，每月 200 万字免费）。主人注册好后，把 Key 存进 secrets，雪耳只存在本机 `%LOCALAPPDATA%\XueerEar`，不进代码仓库。
- 备用：谷歌 Gemini 免费 Key，取主人现有的那把（和 BOT、工具站共用），不和工具站联动。
- 先接哪个都能单独用；主力失败时自动切到备用。

## 四、修问题

每一项都先写能复现的测试或在真机上复现，再改。

1. **漏字**：终端、微信和普通输入框里都有，三个办法都做，边说边出字保留：
   - a. 分小批慢发：键发得慢一点、分批发，让程序来得及处理；
   - b. 少改前面的字：句尾照常边说边出字，前面已经打出来的字，等这句说完再统一改一次；
   - c. 定稿后核对：一句说完后，按雪耳记下的「屏幕上应该是什么」核对，对不上就把这句整句擦掉重打。
   - 先在终端、微信、浏览器各复现一次，再动手。
2. **按右 Alt 有时闪两下**：先查日志，看面板是不是被打开或画了两次，原因查清再修（推测和右 Alt 补发的那个键，或者面板重复显示有关）。
3. **句子开头被吃**：放大倍数沿用上一次的值，不再从 1 倍慢慢往上调；开口前预留的那一小段录音加长一点。
4. **一句被切成好几段**：上一段结尾明显没说完（比如停在「然后我的」「就是」），下一段直接接上，不加句号。
5. **连说两遍的指令**：「发送发送」「撤回撤回」这样连说两遍，也认成指令。
6. 不修：音箱和视频里的声音被收进去，主人自己会避开。
